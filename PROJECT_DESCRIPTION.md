# Описание проекта

## Общее описание

Проект представляет собой **автоматизированный скрипт для входа в веб-игру** на сайте `therebk.com` с использованием библиотеки **Playwright** для управления браузером Chromium. Он предназначен для автоматического заполнения формы логина и пароля с последующим переходом в игровой интерфейс.

Проект предельно минималистичен — состоит из **одного файла** `Run.py` и практически не содержит документации (README.md неинформативен).

---

## Технологический стек

| Компонент | Используемая технология |
|-----------|--------------------------|

## Функциональность скрипта `Run.py`

Скрипт выполняет следующие действия:

1. **Импорт библиотек** — `playwright.sync_api` и `time`
2. **Жёстко заданные учётные данные**:
   - Логин: `'pepsi cola'`
   - Пароль: `'12345678'`
3. **Запуск Playwright** и открытие браузера Chromium в видимом режиме (`headless=False`)
4. **Переход на страницу игры**: `https://therebk.com/game.php`
5. **Ожидание полной загрузки страницы** (`networkidle`)
6. **Заполнение формы**:
   - Поле логина (`#login`) заполняется значением `LOGIN`
   - Поле пароля (`#password`) заполняется значением `PASSWORD`
   - Нажатие на кнопку с текстом «Войти»
7. **Вывод `'Done'`** в консоль после успешного нажатия
8. **Бесконечное ожидание** до нажатия `Ctrl+C`, затем корректное закрытие браузера и остановка Playwright

- Присутствует обработка прерывания (`KeyboardInterrupt`) для корректного завершения

## Недостатки и риски

| Проблема | Описание |
|----------|----------|
| **Жёстко закодированные учётные данные** | Логин и пароль хранятся в открытом виде в коде — небезопасно и негибко |
| **Отсутствие обработки ошибок** | Нет проверки успешности входа, нет обработки сетевых сбоев или отсутствия элементов на странице |
| **Нет модульности** | Весь код в одном файле, нет функций или классов |
| **Нет конфигурации** | Нельзя изменить URL, логин/пароль, режим отображения браузера без правки кода |
| **Отсутствие документации** | README не содержит полезной информации |
| **Зависимость от внешнего сайта** | Работоспособность зависит от стабильности `therebk.com` и структуры его DOM |

## Заключение

Проект представляет собой **учебный или быстрый прототип** автоматизации браузера. Он выполняет одну конкретную задачу, но не готов к использованию в production из-за проблем с безопасностью, гибкостью и надёжностью. При доработке его можно превратить в полноценный инструмент для автоматического входа или мониторинга игрового состояния.
